# MCU 小智

《单片机原理及应用》课程问答网站。项目源于本科毕业设计，使用扣子（Coze 国内版）运行原智能体，通过 FastAPI 提供独立的网页入口。

## 功能

- 课程知识问答、实验指导、代码示例，以及静态电路图检索和动态原理图绘制。
- 手机和桌面浏览器均可使用。网页支持流式回复、代码块、图片上传和配图预览。
- 师生共用一个站内账号，可选择在当前设备记住登录 15 天。同一账号的聊天历史和附件跨设备共享，因此使用同一账号的人可以互相看到这些内容。
- FastAPI + Jinja2 + JavaScript + SQLite，使用 Docker Compose 部署。SQLite 和上传目录独立持久化。

## 运行和部署

1. 按[本地运行说明](docs/run.md)启动。开发和验收默认使用模拟扣子回复。
2. 按[部署与回滚说明](docs/deploy.md)配置 Docker Compose 和 HTTPS 反向代理。使用真实扣子时，需提供已发布智能体的 Bot ID，以及具备发起对话和上传权限的服务访问令牌。真实凭证通过 Compose secret 挂载给后端。
3. 更新镜像前备份 SQLite 与上传目录。镜像更新后检查登录、历史和上传文件是否正常。

## 原毕设归档

[归档目录](archive/README.md)包含原智能体的提示词、两份插件 Python 源码和对应的扣子元数据截图。插件由扣子运行，归档不参与网站运行。若要完整复建智能体，还需从原扣子空间获取模型配置和「51指令系统」「CM3内核」知识库源文件。

## 交接状态

网站已部署 0.3.0，账号级历史迁移通过生产数据库完整性和记录数量检查。原智能体的文字追问、插件配图和图片问答已经真实联调。0.3.0 的公网跨设备续聊及逐段输出仍待实测。

后续开发和日常维护可由课程团队接手。若迁移到其他服务器，按部署文档配置自己的扣子凭证和站内账号，并确认是否需要迁移 SQLite 与上传文件。
